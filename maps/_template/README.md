# Map template — authoring workflow

Copy this folder to `maps/<id>/` and rename the root node (keep it `Map`).
Full spec: `docs/design/maps.md`, node contract: `docs/architecture.md` §7.

## Files in a map folder

| File | Owner | Purpose |
|---|---|---|
| `blockout.tres` | designer | layout spec (`BlockoutDef`): carve/block rects, spawns, lanes, objectives |
| `map.tscn` | generated | playable scene: Ground/Walls/Deco, Nav, Spawns, Cover, Objectives, Bounds |
| `minimap.png` | generated | baked silhouette, 4 px/tile |

## Workflow

1. **Write the blockout.** `blockout.tres` is a `BlockoutDef`. Tile
   coordinates, origin top-left, 1 tile = 32 px. Copy a shipped map
   (`maps/dustworks/blockout.tres`) as the starting point.
   - `carve`: walkable floor `{x, y, w, h, surface}`. Anything not carved is
     **solid void** — buildings, walls between lanes, the map border.
   - `blocks`: geometry painted into Walls
     `{x, y, w, h, material, low_cover, cover, penetrable}`.
     `material`: `concrete_block` | `brick` | `container`. `low_cover: true`
     picks a cover tile via `cover`: `crate` | `sandbag` | `car`.
   - `spawn_rects`: `{team, x, y, w, h, count}` — 12 per team for TDM.
   - `lanes`: `{id, from, to}` — AI lane graph; cover points inherit lane tags
     from proximity, so a block with no lane nearby yields unused cover.
   - `objectives`: `{id, order, x, y, w, h, capture_time, lock_on_capture}`
     (Battle only).
2. **Generate + bake**, in this order (each needs the previous):
   ```bash
   tools/godot.sh --headless --path . -s tools/build_map.gd   -- --map=<id>
   tools/godot.sh --headless --path . -s tools/bake_minimap.gd -- --map=<id>
   ```
   `build_map.gd` paints both tile layers, bakes `Nav` from the wall colliders,
   and generates 12 spawn markers per team (grid jitter, fixed seed — rebuilds
   are diff-stable) plus one `CoverPoint` per block face toward open floor.
3. **Polish in the editor.** Paint `Deco` (props, no collision), move/retune
   `CoverPoint`s (`lean_dir`, `quality` 0..1, `lanes`), add `ObjectiveZone`s.
   Keep lanes/spawns/objectives intact — sims and fairness depend on them.
4. **Author `data/maps/<id>.tres`** (`MapDef`): `scene_path`, `supported_modes`,
   `briefing`, `minimap_path`, `ambience_id`, `music_id`, `lighting_preset`.
5. **Verify.**
   ```bash
   tools/godot.sh --headless --path . tools/probe_world.tscn -- --map=<id>
   tools/godot.sh --path . -- --shot=res://tools/shot_map.tscn:15:reports/screenshots/<id>.png
   ```
   Then a seeded sim (`--sim=<id>:...`) for fairness/no-stall.

## Do not

- Re-run `build_map.gd` after painting `Deco` — it overwrites the scene. Move
  the authored scene to a copy first if you must rebuild.
- Rename the layer nodes (`Ground`, `Walls`, `Nav`, `Spawns`, `Cover`,
  `Objectives`, `Bounds`) — `World` resolves them by name.
- Hand-edit tile collision/nav layers — they live on
  `assets/sprites/tiles/kangur.tres` (generated by `tools/gen_tiles.gd`).
